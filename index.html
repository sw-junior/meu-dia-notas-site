Política de privacidade

A extensão processa localmente nomes e notas fornecidos pelo usuário e os dados visíveis da tabela de notas na página ativa. Usa essas informações somente para comparar a planilha com os campos do portal. Também observa o conteúdo visível e o endereço da página para suspender a conferência quando o contexto muda. Acompanha o foco e as alterações nos campos de notas para mostrar o aluno selecionado e comparar os valores. Não consulta o histórico geral do navegador nem registra teclas digitadas fora dessa finalidade.

Nenhum dado é enviado pelo código da extensão a servidores, vendido ou usado para publicidade. Não há telemetria, cookies próprios, leitura de senhas ou armazenamento persistente. Os dados permanecem na memória até o fechamento do painel ou recarregamento da página. Arquivos originais permanecem no computador do usuário.

activeTab permite acessar temporariamente a aba após a ação do usuário. scripting permite abrir o painel local de conferência na Sala do Futuro Professor. A extensão não altera nem salva os campos de notas do portal.

O tratamento realizado pelo próprio portal e pela loja segue as políticas dos respectivos serviços.

Contato do responsável: Walter da Silva Junior — walter.sjr@hotmail.com.

O uso dos dados é limitado à função de conferência descrita. Os dados não são usados para publicidade, análise de crédito, empréstimos ou finalidades não relacionadas. O uso das informações respeita a Política de Dados do Usuário da Chrome Web Store, incluindo os requisitos de Uso Limitado.

Para encerrar o processamento, feche o painel ou recarregue a página. Não mantemos uma base remota de alunos ou notas a excluir. O arquivo importado e os registros do portal são controlados pelo usuário e pelo portal, respectivamente.

Esta política se aplica à extensão Meu Dia — Notas 0.3.0. Mudanças de práticas serão informadas nesta página e, quando necessário, na extensão. A extensão é independente e não possui vínculo com a Seduc.

Esta página é hospedada no GitHub Pages, que pode processar dados técnicos de acesso conforme a política de privacidade do GitHub. A página não usa formulários, rastreadores ou recursos de terceiros.
